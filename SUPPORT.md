# Support

Macroblock is community-supported alpha software.

For setup and usage questions, first check the [README](README.md), especially
the Windows requirements, safety abort, and contributor commands. Then search
existing [GitHub issues](https://github.com/IamOumarIbrahim/macroblock/issues).

Open a bug report when behavior is reproducible. Include:

- whether you ran from source or `Macroblock.exe`;
- the Macroblock version or commit;
- Windows and Python versions;
- monitor layout and scaling when coordinates or overlays are involved;
- minimal steps, expected behavior, and actual behavior;
- relevant logs or screenshots with private information removed.

Never upload a private `.mbk` file without reviewing every text value and
coordinate. For vulnerabilities or safety bypasses, follow [SECURITY.md](SECURITY.md)
instead of opening a public support issue.
